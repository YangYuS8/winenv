# Support

[简体中文](./SUPPORT.zh-CN.md)

Start with the [documentation](https://yangyus8.top/winenv/) and `win help`. Run `win check` before reporting manager or command-resolution problems.

Use the repository issue forms for:

- reproducible defects;
- focused feature proposals;
- documentation or translation problems;
- usage questions that remain after reading the guides.

Provide `win ver`, the Windows build, PowerShell version, exact command, expected result, actual result, and sanitized text output. Do not post secrets or screenshots containing account data. This community provides best-effort support; there is no service-level agreement or guaranteed response time.

Security vulnerabilities must use the private process in [SECURITY.md](./SECURITY.md). Sensitive conduct reports follow the [Code of Conduct](./CODE_OF_CONDUCT.md).

WinGet, Scoop, mise, Windows, and third-party packages are separate projects. If Winenv passes a request correctly and the failure occurs entirely upstream, report it to that project with Winenv's diagnostic context.
